Day Support

Day puts an event on your existing calendar in one line. Type a sentence, check the preview, press Return. Start here if Day does not schedule what you expected or cannot reach your calendar.

Day requires macOS 14 or later. Email pzarudnev93@gmail.com if you still need help. If you are testing a TestFlight build, send feedback from the TestFlight app.

Schedule an event in one line

Press ⌃⌥Space (the default; you can change it in Settings) from any app. Type a line such as Call Sarah tomorrow at 3pm for 45 minutes. The preview shows the title, date, start and end time, and destination calendar. Press Return to save. Change 45 to 30 and the end time updates before you save.

Esc closes the panel without saving, and the main window stays closed.

Day asked “When?”

You pressed Return on a line with no time. Day kept your exact text and keyboard focus, and the first Return saved nothing.

  1. Add a time to the text, for example Call Sarah tomorrow 3pm, or pick a time in the preview.
  2. Press Return once more. The preview resolves, and one Return creates one event.
  3. Pressing Return again on the same bare text changes nothing: no duplicate, no lost text.

Calendar access

Day asks for Calendar access when you press Return to save your first event, or any time from the banner or Settings. Typing and previewing work without it.

If you denied access

  1. Open System Settings → Privacy & Security → Calendars and enable Day.
  2. Return to Day and press Return again. Your text is still in the panel.

No writable calendar, or the calendar is read-only

  1. In Day, open Settings → Calendar for new events.
  2. Choose a calendar that allows changes, or choose Automatic.
  3. Read-only calendars, such as some subscribed calendars, cannot receive new events. If the list has no writable calendar, add one in Calendar or Internet Accounts, then reopen Day.

Day shows the calendars macOS Calendar already syncs. It does not add accounts itself. You can revoke Calendar access at any time in System Settings.

Optional Markdown notes

Notes are off by default. To keep them, open Settings → Markdown notes → Choose folder. Day keeps one plain YYYY-MM-DD.md file per day in that folder, and you can open or edit it in any text editor.

  • ⌥Return keeps a note, and ⌘Return saves a task.
  • Note on a meeting adds a meeting note.
  • All of these need a folder; scheduling does not.
  • Existing files are never rewritten beyond appended lines.
  • Tasks carry forward for up to 30 days; check them off or defer them.

Widgets

Widgets show what is next on your calendar, and event rows open that event in Day. Checking off a task and the meeting Note action need a notes folder; without one, the widget shows calendar events only.

The event did not save, or the text disappeared

Day keeps your text when a save fails. Check the message above the field: it usually points to Calendar access or a read-only calendar. Fix that, then press Return again.

If the text is gone, or the message does not help, email pzarudnev93@gmail.com with your macOS version, the steps, the expected and actual result, and a screenshot when it contains no personal data.

Report an issue

Email pzarudnev93@gmail.com with:

  • The Day version and build from Day → About Day.
  • Your macOS version.
  • What you did, what you expected, and what happened.
  • Whether Calendar access is on, and whether the notes folder is local or synced.

If you are testing a TestFlight build, you can also send feedback from the TestFlight app; it includes the build automatically.

Do not send private attachments

Send only what you are comfortable sharing. Do not attach your notes folder, a calendar export, or screenshots containing private notes, events, email addresses, or other personal data. If a screenshot is needed, use a disposable notes folder and a test calendar, or redact the private parts.
