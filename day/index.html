Put it on your calendar in one line.

Day is a Mac menu-bar app for the moment you need to schedule something while you are busy doing something else. Type a sentence, check exactly what it will create, press Return. The event lands on the calendar you already use.

Type it. Preview it. Return.

  1. Open the panel from anywhere Press ⌃⌥Space in whatever app you are in. The Day panel appears over your work; the main window stays closed. You can change the shortcut in Settings.
  2. Type one line Write it the way you would say it: Call Sarah tomorrow at 3pm for 45 minutes. Day reads the title, date, time, and duration from the sentence.
  3. Check the preview Before anything is written, Day shows exactly what it will create: title, date, time, duration, and the calendar that will receive it. If the preview is not what you meant, fix the line.
  4. Press Return Return confirms what the preview showed and saves the event to your existing calendar. Esc closes the panel without saving.

No time in the line? Day asks “When?”

Type Call Sarah and press Return, and Day asks When? instead of guessing. Your text stays exactly as you wrote it, keyboard focus stays in the panel, and nothing is written.

Add the time — tomorrow 3pm — and the preview resolves. One Return then creates one event.

Press Return again on the same bare text and nothing changes: no duplicate, no lost text. If a calendar is not writable or an event fails to save, the text stays in the panel so you can fix it and try again.

Works with your calendar

Day works with the calendars macOS already has — iCloud, Google, Exchange, or anything else you added in Calendar or Internet Accounts. Events are read and written through Apple’s EventKit. Day does not add accounts and does not run its own sync service.

Day asks for Calendar access when you press Return to save your first event, or any time from the banner or Settings. If you decline, Day tells you what to change and offers a button straight to System Settings › Privacy & Security › Calendars, and your text stays in the panel. Scheduling needs that permission; typing and previewing do not. You can revoke access at any time.

You choose which calendar receives new events. Read-only calendars, such as some subscriptions, cannot take new events; Day says so instead of failing silently.

Optional Markdown records

Scheduling does not need a folder. If you want a written record too, choose a folder in Settings and Day keeps one plain Markdown file per day, named YYYY-MM-DD.md, beside your calendar.

  • One file per day, open and editable in any text editor.
  • Existing files and preferences are respected.
  • Open tasks carry forward for up to 30 days; check them off or defer them.
  • Notes are opt-in and explicit. The shortcut is for scheduling.

An explicit action on a calendar event adds a note to that meeting. It needs a folder, and only that action targets a meeting.

Menu bar, shortcut, and settings

Day lives in the menu bar. The global shortcut — ⌃⌥Space by default, configurable — opens the panel from any app without opening the main window.

Settings cover the shortcut, the calendar for new events, time format, appearance, working hours, open at login, and the optional notes folder.

Widgets

Desktop widgets show what is next on your calendar, and event rows open that event in Day. You can check off a task from a widget too — but tasks need a folder, and the widget says so rather than pretending otherwise.

Privacy first

No account, no sign-in, no hosted sync, no analytics, no third-party SDK. Day reaches your calendar through EventKit only after you grant permission. If you put the notes folder in iCloud Drive, Dropbox, OneDrive, or another synced location, that provider syncs the files under its own policy — Day does not.

Read the Day privacy policy, or visit Day support if something is not working.
